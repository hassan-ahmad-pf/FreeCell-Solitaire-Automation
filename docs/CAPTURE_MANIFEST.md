# FreeCell capture manifest

Capture these states from the installed FreeCell build before cropping assets.
The list is intentionally independent of Spider's screen names.

## First launch

- Terms & Conditions card
- Terms page
- Privacy Policy page
- tracking permission
- accepted main menu

## Main navigation

- main menu
- Play entry and any difficulty/deal picker
- Statistics, including the bottom reset control
- Options, including every visible toggle and slider
- Help top and bottom
- About top and bottom
- About FAQ top and bottom
- More Games top and scrolled content
- Choose Look Surface and Cards tabs

## Gameplay

- fresh FreeCell table
- all four free cells and four foundations
- eight tableau columns
- stock/deal control, if present
- undo and hints
- lower/raise control, if present
- in-game menu and every drawer action
- abandon/replay/new-game dialogs
- options/help/FAQ from the table

## QA and victory

- About emblem before and after the debug gesture
- QA keypad and code entry
- QA panel
- active FreeCell table with Complete Game available
- victory/ranking screen
- victory navigation and return to menu

Each crop must come from a FreeCell screenshot on the target device. Never
substitute an inherited Spider crop merely because the control has the same
label.
